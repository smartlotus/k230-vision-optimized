10,000–20,000 位置扩量、真实相机精度及 K230 原生 FPS、延迟、内存和长时间稳定性均为 **NOT RUN**。正确启动区至少 80%、中位误差不超过 200 mm、P95 不超过 500 mm 的 Pilot 门槛未达到。

## 时间间隔诊断

验证集 240 个相邻位移的中位数为 168 mm，采样间隔中位数为 0.441 s。其中 94.2% 的位移至少一个轴超过滤波器局部传播的一格 50 mm。全场仍有概率底。保持训练后的 A 权重和视觉温度不变，按实际间隔逐帧扩大软传播半径，模拟尺度 500、800、1,200 mm/s 的验证中位误差约为 669 mm、645 mm、715 mm，原版为 785 mm。800 mm/s 的验证 P95 约为 1,963 mm，首帧启动区判断仍为 5/10。该消融仅供验证集诊断，未改部署参数，未在测试集或实车运行。 [消融数据](MOTION_VAL_ABLATION.json)
