## 发现：旧备用入口不是 R2 自包含入口

`board_temporal.py` 的 `run()` 在函数体内导入 `board_probe` 并调用其 `run()`。R2 ZIP 没有 `board_probe.py`。如果将该函数当作本包独立入口，包内依赖不完整；板上其他目录恰巧有同名模块也不应当作本包的可靠依赖。

R2 README 正确使用 `from board_multiroute import run`。该模块仅从 `board_temporal` 取 `BenchDecoder` 类，不执行旧 `run()`；其余本地依赖全部在包内。保持使用这一明确入口。见 [ENTRY_DEPENDENCIES.json](ENTRY_DEPENDENCIES.json)。没有替换交付模型或更改原有算法。

## 当前不能确认的项目

设备当前被其他线路使用，用户已要求仅电脑端检查。因此仍未验证真实取帧、当前固件下的 ndarray / AI2D / KPU 执行、原生缓冲释放、原生 FPS 或连续运行稳定性。电脑端 ONNX CPU 执行不等同于量化 KModel 在 K230 上运行。

本次没有做实际定位正确率、道路检测或整车测试。
