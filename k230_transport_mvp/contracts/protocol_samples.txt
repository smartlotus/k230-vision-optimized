UART protocol v1 ? 2026-10-31
2026-11-09 additive S v1: see ../MATERIAL_COMMUNICATION_V1_20261109.md.
S header (indices 0..15): S,tx_seq,1,status,camera_id,frame_id,timestamp_ms,profile_id,width,height,IMAGE_PX,is_simulated,complete,count,reason,source_session.
Each of count (0..3) objects adds: color_id,u_px,v_px,semimajor_px,semiminor_px,angle_rad,score_hint,stable,geometry_valid.
S is a complete material image observation, not control. Source profile SHA256 and 128-bit session are explicit bindings.
OK needs complete=1,count=1..3. NOT_FOUND needs complete=1,count=0. UNKNOWN/UNAVAILABLE/ERROR need complete=0,count=0,reason.
S keeps the same framing, line bound and shared increasing sequence as C/A/V. No implicit session reset.
ASCII LF-terminated $BODY*HH\n, XOR8 of BODY; uppercase hex. Max frame 768 bytes.
Missing optional value: -. No CSV quoting. Nonempty tokens; ordinary tokens <=96 ASCII bytes; V image_profile <=384 encoded bytes.
C fields: C,tx_seq,command,mode,target_id,station
command: MODE/STOP/PING. MODE: IDLE/QR/COLOR/RING/LANE/TOP/SELFTEST. target_id optional 1..6.
STOP/PING require all last three fields -. No motor commands are defined.
A fields: A,tx_seq,command_seq,status,reason
A status: ACK/BUSY/DONE/ERROR/UNKNOWN/STOPPED/PONG. ACK is receipt only; DONE alone is completion.
V fields (indices start at 0):
0 V; 1 tx_seq; 2 status; 3 kind; 4 camera_id; 5 frame_id; 6 timestamp_ms; 7 target_id;
8 coord_frame; 9 u_px; 10 v_px; 11 x_mm; 12 y_mm; 13 angle_deg; 14 score_hint;
15 stable; 16 is_simulated; 17 calibration_id; 18 station; 19 plane; 20 image_profile;
21 target_pose_valid; 22 reason; 23 raw_payload.
Boolean: 0/1. score_hint: 0..100 heuristic, not calibrated confidence. Finite numbers only, absolute max 10000000.
frame_id and timestamp_ms: 0..4294967295; non-OK may have frame_id=- when no image exists.
status: OK/NOT_FOUND/UNCALIBRATED/UNAVAILABLE/ERROR. kind: QR/COLOR/RING/LANE/TOP.
coord_frame: IMAGE_PX/ROBOT_MM/WORLD_MM/NONE. Non-OK and IMAGE_PX/NONE have no x_mm/y_mm.
OK ROBOT_MM/WORLD_MM requires both x_mm/y_mm. IMAGE_PX never authorizes motion.
image_profile: canonical JSON (sorted object keys, compact lists), then percent-escape reserved bytes. Decode to a complete dict.
reason/raw_payload: percent-escape percent/comma/star/dollar/control/non-ASCII UTF-8 bytes as %HH.
Diagnostic reason may truncate to 96 encoded bytes including ...; calibration/profile identity never truncates.
No sequence wrapping: per sender session shared tx_seq across C/V/A, strictly increasing 0..65535.
A command_seq refers to an input command; it need not equal A tx_seq. Repeated command_seq with progressing ACK/DONE is valid.
Only explicit reset with motors independently disabled starts a session. Reset never resolves uncertain physical motion.
Local monotonic timestamps; do not compare sender ticks directly with STM32 ticks. Receiver records its local receive time.
UartAdapter True return means accepted into bounded software TX queue, not physical delivery or consumer acknowledgement.
