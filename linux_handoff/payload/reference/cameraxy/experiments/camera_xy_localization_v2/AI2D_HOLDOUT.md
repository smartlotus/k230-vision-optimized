# 冻结 CameraXY 的 AI2D 预处理回放

正式训练使用 Pillow 把 320×180 的合成图缩至 160×90，上下各补 3 行 114。板端工程输入链先从相机得到 640×360 的 RGB，再用 AI2D half-pixel 缩至 160×90 并补相同的行。这次比较冻结 learned_map 的同图配对结果。

## 实测张量复核

在固定四倍缩小下，half-pixel 取每个 4×4 输入块中央四个像素的平均，整数输出按半值向上取整。主机实现对五组历史板端输入逐字节复现全部 230,400 个输出字节，覆盖常量、渐变、单像素线、棋盘格和一张合成留出图。报告绑定原始输入、输出、规格与历史板端报告的 SHA256。

## 正式留出回放

逐张验原始 RGB 指纹。每个 320×180 原图分别通过原训练路径、Pillow 放大至 640×360 再由 Pillow 缩小、同一 640×360 张量经 AI2D 主机实现缩小。三路共用冻结权重、解码、阈值与校准。训练路径复现 G5 的 Top-1 和 Top-5 命中数。下表为 50 mm 命中计数。

| 测试组 | 帧 | 训练 Pillow Top-1 / Top-5 | 经 640×360 的 Pillow | 经 640×360 的 AI2D 主机实现 |
|---|---:|---:|---:|---:|
| 空间留出 | 2,000 | 623 / 1,766 | 621 / 1,763 | 622 / 1,755 |
| 配对外观留出 | 1,000 | 314 / 680 | 316 / 684 | 312 / 666 |
| 重复直道子集 | 1,488 | 0 / 1,099 | 0 / 1,100 | 0 / 1,077 |

前两行组成全部 3,000 帧，重复直道为其中的子集。AI2D 回放相对训练路径改变了 271 帧的首候选和 789 帧有序五候选；重复直道三路首候选命中均为零。外观留出中，AI2D 回放的候选集合平均置信度为 84.69%，实际集合命中率为 66.60%，Brier 分数约 0.234。完整回放统计包含每组的配对命中变化、误差、置信度和像素差。

本回放限定在合成图、冻结 learned_map 和 CPU 推理。640×360 中间张量由主机构造。真实相机的解码、颜色、缩图和光心真值需要现场验证。单点验收为 HOLD；所选 fused_map 的板端验证待完成。
